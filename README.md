## Projeto em destaque | Featured Project

### Sistema de Gerenciamento de Biblioteca | Library Management System

Aplicação em Python integrada ao MySQL para gerenciar clientes, autores, livros e empréstimos.

A Python application integrated with MySQL to manage customers, authors, books, and loans.

**O que o projeto pratica | What this project explores**

- Operações CRUD;
- Consultas SQL e relacionamentos entre tabelas;
- Integração de uma aplicação Python com MySQL;
- Separação entre fluxo principal, lógica da aplicação e acesso a dados;
- Uso de variáveis de ambiente para configuração.

- CRUD operations;
- SQL queries and relational database concepts;
- Python and MySQL integration;
- Separation of application flow, business logic, and data access;
- Environment variables for configuration.

**Tecnologias | Technologies:** Python, MySQL, SQL, `mysql-connector-python` e `python-dotenv`.
